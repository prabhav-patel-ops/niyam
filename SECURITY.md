# Security model

The browser talks only to its own origin. Operator credentials, data paths and provider endpoints are configured on the backend. Browser sign-in uses HttpOnly, SameSite Strict cookies, with Secure required in production. Legacy browser-stored bearer tokens and backend URLs are discarded. Explicit API clients can still use the returned bearer token. Tokens and rotating recovery codes are stored as SHA-256 hashes; passwords use salted scrypt. Password recovery revokes sessions.

Unsafe cross-origin requests are rejected, including explicit cross-site fetches. Production rejects plaintext application requests except local liveness probes. The included proxy terminates TLS, and Uvicorn trusts forwarded client information only from that proxy address. Trusted-host checks and a same-origin Content Security Policy apply. Only `web/` is served; `.env`, data and account storage must remain outside it.

Private resources are scoped by account. Authentication throttles persist in SQLite and return Retry-After. Sessions, accounts, jobs, strategies, attachments and watches have bounded counts. The executor has two worker slots and a bounded submission queue. Request limits count actual bytes, including chunked bodies. CPU-heavy document extraction is isolated in disposable processes with a timeout and two slots; Linux workers also enforce 512 MiB address-space and 10-second CPU limits. Windows does not provide those POSIX resource limits, so deployment memory limits remain essential. Compressed Word documents and PDF pages/text are bounded. Scanned PDF OCR is unavailable.

AI output is validated against a closed, typed rule language; it is never executed as Python, shell or SQL. Provider responses are limited to 1 MiB, with bounded retries and two concurrent interpretation slots. Untrusted text is escaped, parameter identifiers are constrained, prototype-related object paths are blocked, external links are limited to HTTP(S), and CSV exports neutralise formula-like strings. A validated structure does not prove that the AI understood the user's intent.

Configured model/search providers receive relevant strategy text and attachments. Search queries are instructed to contain public method names only; this is not a formal guarantee against model-driven disclosure. Choose providers and usage policies appropriate to the data. API connections and feed targets can only be configured by the operator; do not expose environment editing to end users.

One backend process owns a state-directory lock. SQLite, rate limits and local execution are designed for that deployment boundary, not multiple replicas. Host access, TLS, backups, encryption at rest, edge traffic controls, monitoring, capacity planning and patch maintenance remain operator responsibilities. No independent penetration-test certification is claimed. Consult the current [audit record](docs/PRODUCTION_AUDIT.md) and branch CI before launch.

Do not commit private keys, datasets, account databases, session tokens or recovery codes. To report a vulnerability, contact the repository owner privately; do not post credentials or exploit data in a public issue.
